  # QMS-RISE

  **Quality Management System – RISE** is a web-based academic quality management dashboard built for tracking, visualising, and managing institutional quality metrics (e.g. CLO, CQI, QS indicators) with a focus on Malaysian higher-education contexts.

  This repository contains the front-end application, data import scripts, seed SQL, and deployment configuration for Netlify + Supabase.

  ---

  ## Features

  - **Dashboard views** for quality metrics and KPIs
  - **Data import pipeline** from CSV (staff, students, timetables, enrolments)
  - **Supabase-backed storage** for structured academic data
  - **Netlify-ready deployment** with static hosting and serverless functions
  - **Seed scripts** for FAQs and developer documentation
  - **Branding assets** (logos, banners, promotional videos)

  ---

  ## Tech Stack

  - **Front-end:** HTML, CSS, JavaScript (`index.html`, `qms.html`, `app.js`, `styles.css`)
  - **Back-end / Data:** Supabase (PostgreSQL), SQL seed files
  - **Deployment:** Netlify (`netlify.toml`, `netlify/` functions)
  - **Data Import:** Python (`import_data.py`, `requirements.txt`)
  - **Assets:** Logos, images, and videos for UI and promotional use

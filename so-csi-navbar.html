◆ So-CSI Responsive Navbar

This modular navigation component features the So-CSI cyber-security aesthetic with neon glow effects, Space Grotesk typography, and responsive design. The navbar includes hover states with color-coded accent glows (cyan, violet, magenta, gold, green), a pulsing mint-green department badge, and smooth animations throughout.

Key Features

• Neon Glow Effects: Multi-layered box-shadows create authentic cyberpunk aesthetics
• Space Grotesk Typography: Bold, modern headings with Inter for body text
• Glassmorphism: Backdrop blur with semi-transparent backgrounds
• Responsive Design: Mobile-first with hamburger menu and collapsible navigation
• Hover States: Each nav item has unique accent color on hover
• Accessibility: Focus-visible states with cyan outlines
• Smooth Animations: Cubic-bezier transitions for natural motion

Integration with QMS RISE

Copy the HTML structure and CSS into your QMS RISE project. The navbar uses CSS variables for easy theming. Customize colors in the :root section. The component is fully modular—remove or add nav items as needed. For QMS RISE integration, replace your existing .topbar with this enhanced version.
